# Github



### 1 Github 常用词汇

custom /ˈkʌstəm/ 

1. 自定义的、定制的（形容词）
2. 习俗、惯例（名词）

记忆技巧： 在 GitHub、Linux、ChatGPT、VS Code 等开发环境中，看到 `Custom`，大多数情况下可以直接理解为“自定义”。

### 2 Github Notification   通知

| 英文             | 更准确的翻译           |
| ---------------- | ---------------------- |
| Assigned         | 被指派的、分配给我的   |
| Mentioned        | 被提及的、有人提到了我 |
| Team mentioned   | 所属团队被提及         |
| Review requested | 收到代码审查请求       |

## 💻 结合 GitHub 场景理解

1. Assigned — 被指派

Someone assigned an issue to you.

有人把一个 Issue（问题或任务）分配给你。

- `assign` = 分配、指派
- `assigned` = 已被指派的
- `assignee` = 被指派人、负责人

注意：签名通常使用 `signature` 或 `sign`。

2. Mentioned — 被提及

Someone mentioned you in a comment.

有人在评论中通过 `@你的用户名` 提到了你。

- `mention` = 提及
- `mentioned` = 被提及

注意：注意通常是 `notice` 或 `pay attention to`。

3. Team mentioned — 团队被提及

Someone mentioned your team.

有人通过 `@组织名/团队名` 提到了你所在的团队。

例如：`@backend-team`

4. Review requested — 收到代码审查请求

Someone requested your review on a pull request.

有人请求你审查一个 Pull Request（PR）。

- `review` = 审查、评审
- `request` = 请求
- `reviewer` = 审查者
