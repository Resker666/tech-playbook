## Vocabulary

### encrypt

- **词性**：verb（动词）
- **音标**：/ɪnˈkrɪpt/
- **含义**：加密；将信息转换为未经授权者难以读取的形式。
- **常用搭配**：encrypt data、encrypt files、encrypt traffic、encrypt sensitive information

**技术例句**

> We need to encrypt sensitive data before uploading it to the server.

在将敏感数据上传到服务器之前，我们需要先加密。

> The device encrypts the log file before sending it to the cloud.

设备在把日志文件发送到云端之前，会先对其进行加密。

**相关词汇**

| 单词 | 词性 | 含义 |
| --- | --- | --- |
| decrypt | verb | 解密 |
| encryption | noun | 加密（过程或技术） |
| decryption | noun | 解密（过程） |
| encrypted | adjective | 已加密的 |
| encryption key | noun phrase | 加密密钥 |

**区分**：`encrypt` 是动词；`encryption` 是名词。加密（encryption）不等于哈希（hashing）或编码（encoding）。
