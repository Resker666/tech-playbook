# Windows Debug

记录 Windows 使用过程中遇到的问题、排查过程、调试命令以及最终解决方案。

这个目录更偏向实际问题复盘，而不是系统性的 Windows 教程。

Windows 开机后自动弹出 `amdafdapp.exe` / Terminal 窗口的问题排查与解决。

主要涉及：

- Windows Task Scheduler
- AMD 驱动组件
- 启动项排查
- Service 排查
- Parent Process 追踪
- PowerShell 调试命令
