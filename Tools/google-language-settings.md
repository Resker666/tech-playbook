# Google 网页服务语言切换技巧

> 记录日期：2026-11-24  
> 验证状态：Gemini 网页端实测有效

## 问题描述

访问 Gemini 网页端时，默认显示繁体中文，希望切换为简体中文，同时不修改 Google 账号、浏览器语言和网络环境。

## 解决方法

通过 URL 参数 `hl` 指定界面语言。

```text
https://gemini.google.com/?hl=zh-CN
```

直接访问上述网址即可切换为简体中文。建议将该网址保存至浏览器书签。

## 常用语言参数

| 参数 | 语言 |
|---|---|
| `hl=zh-CN` | 简体中文 |
| `hl=zh-TW` | 繁体中文（台湾） |
| `hl=zh-HK` | 繁体中文（香港） |
| `hl=en` | 英语 |
| `hl=ja` | 日语 |
| `hl=ko` | 韩语 |

## 方法优势

- 无需修改 Google 账号设置。
- 无需修改浏览器首选语言。
- 无需切换代理节点。
- 可以通过不同书签快速切换语言（需确认目标服务支持）。

## 经验延伸

Google 的部分网页服务支持 `hl` 参数。当遇到网页显示语言不符合预期时，可以优先尝试该方法。若 URL 已有查询参数，使用 `&hl=zh-CN` 追加，避免重复设置 `hl`。

本次仅验证 Gemini 网页端的 `zh-CN` 参数；其他服务和语言参数的支持情况需要单独验证。
