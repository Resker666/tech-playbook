# Tech Playbook

A personal engineering playbook for practical development, debugging, Linux, Git, Docker, and server operations.

记录日常开发、问题排查和技术实践中真正使用过、验证过、值得沉淀的命令、方法和经验。

这个仓库更偏向 **实践记录与问题解决**，而不是系统性的教程。
